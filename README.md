One image summing up the world's news of Tuesday 24 November 2026, for
make.fun's "Sum up 24 November's world news in one image" bounty.

The front page leads with the COP31 climate talks collapsing in Antalya
with no deal on fossil fuels, plus a Russian warship sunk at Benghazi, a
factory fire killing 24 in Indonesia, drone strikes on Kyiv, cost-of-living
protests in Lisbon, and Verstappen winning the Las Vegas Grand Prix.

`main.py` (Python 3.13, stdlib only) copies `entry.png` to
`/output/entry.png`. The run is deterministic: both runs write the same
bytes. No network access.
